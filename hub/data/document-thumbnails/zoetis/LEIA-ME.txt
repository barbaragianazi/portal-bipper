Formato recomendado: retrato ou paisagem, JPG ou PNG, ex: 800x600px (a miniatura e cortada em "cover").

Isso vale só para os arquivos de demonstracao do catalogo (sem arquivo real por tras).
Arquivos enviados de verdade pelo usuario (upload) ja geram miniatura e preview reais
automaticamente (PDF via PDF.js, Excel via SheetJS) - nao precisam de print manual.

PPT/PPTX nao usa miniatura nem preview (sem biblioteca client-side capaz de renderizar
o conteudo real) - continua so com o icone generico.

---

MINIATURA PADRAO (fallback) para PDF e Excel
---------------------------------------------
Alem das miniaturas especificas acima, existe um fallback generico: uma unica
imagem para "todo PDF sem miniatura propria" e outra para "todo Excel sem
miniatura propria". Isso cobre os documentos antigos/de catalogo que nao tem
arquivo real por tras (sem dataUrl) e nao tem uma miniatura especifica cadastrada.

Suba os arquivos com estes nomes exatos, nesta mesma pasta
(hub/data/document-thumbnails/zoetis/):

  - generico-pdf.jpg      -> usado em qualquer .pdf sem miniatura propria
  - generico-excel.jpg    -> usado em qualquer .xls/.xlsx/.xlsm sem miniatura propria

Prioridade de exibicao para um documento:
  1) miniatura real gerada automaticamente (upload com dataUrl - PDF.js/SheetJS)
  2) miniatura especifica cadastrada no JSON (campo "thumbnail")
  3) miniatura generica (generico-pdf.jpg / generico-excel.jpg)
  4) icone generico do tipo de arquivo (ultimo recurso, sem imagem nenhuma)

O mesmo par de arquivos (generico-pdf.jpg / generico-excel.jpg) tambem deve
ser enviado em hub/data/document-thumbnails/default/ para cobrir marcas/
workspaces que nao sejam Zoetis/Agro Amazonia.
